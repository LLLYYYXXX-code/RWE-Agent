# RWE-Agent

> 面向临床医生的端到端真实世界证据（RWE）自动化分析 Agent：基于 Claude 大模型与 SciencePal Harness 框架，接入 MIMIC-IV 医疗数据库，只需提出问题并沟通确认，即可完成「问题结构化 → 可行性验证 → SQL 取数 → 统计分析 → 报告生成」的全链条探索性分析。

**在线示例**：[SciencePal 分析过程分享](https://sciencepal.ai/share/0bd80dac-3540-43a8-9eda-81d63c3e7fc1)

## 背景与动机

传统 RWD→RWE 研究需要医生提出命题、数据工程师取数、统计师分析并撰写报告，多角色协作、周期以周计。其中大量步骤重复性高、具备被 AI 承接的潜力。本项目面向**低严谨性要求的探索性分析场景**，验证不依赖重型框架、用 LLM Agent 完成轻量级初步分析的可行性。

⚠️ **适用边界**：本项目定位为探索性分析的提效工具，输出结果供研究者参考与复核，不构成临床决策依据，不替代规范的真实世界研究流程。

## 系统架构

将临床研究生命周期拆解为 **4 大业务模块、9 个原子化 Skill**：

| 模块 | 包含 Skill（按仓库实际命名替换） | 说明 |
|---|---|---|
| ① 研究问题结构化 | PICOS 结构化、可行性验证 | 将模糊的临床问题转译为结构化研究要素，并评估数据库可行性 |
| ② 数据获取 | SQL 自动生成、变量解码 | 引入 MIMIC-IV 数据字典与表结构，提升 SQL 生成与临床变量解释准确率 |
| ③ 统计分析 | 生存分析、基线统计等 | 按研究设计自动执行统计分析 |
| ④ 结果输出 | 报告生成 | 汇总分析结果，生成结构化报告 |

工程要点：

- 通过**系统提示词**实现 Skill 调度顺序控制、角色切换与多步自治，降低多步执行中的任务脱轨与目标漂移
- 引入 **MIMIC-IV 数据字典与表结构**作为上下文，降低 SQL 生成与临床变量解码的幻觉率

## 验证案例

**命题**：ICU 脓毒症患者升压药选择（去甲肾上腺素 vs 多巴胺）与 28 天病死率的关系（经典真实世界研究命题，参照 SOAP II 临床试验背景）。

**结果**：系统自动完成取数、分析与报告，结论与医学金标准方向一致，并在分析流程中处理了适应证混杂（confounding by indication）问题。

## 已知局限与可能的改进方向
> 以下为基于当前实现的观察与设想，尚未验证可行性，也未列入开发安排。

- 当前流水线以「跑通全链路」为首要目标，部分 Skill 的提示词尚未充分调优
- **可探索方向**：
  - 用消融实验量化各模块（数据字典注入、提示词调度策略）对结果稳定性与质量的贡献
  - 引入统一的 Skill 接口规范，降低多人协作时的集成成本
  - 为关键 Skill 建立小型评测集，使「粗糙但可跑」逐步转为「可回归验证」
- 分工说明：本项目为团队课程项目，本人担任组长，负责前期 RWE 工作流调研、流程拆解与系统集成
